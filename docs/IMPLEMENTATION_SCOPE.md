# PathWeave 1.1 work scope

User request: create a job-specific CV from the user's own experience, skills,
certificates and optional photo; repair current limitations; commit to GitHub.
LinkedIn and VietnamWorks account linking are explicitly out of scope.

CV generation is local and deterministic. It must never turn a requirement in a
job description into a claim about the candidate. Users review and edit a draft
before exporting or attaching it to an application. No application is submitted
automatically.
